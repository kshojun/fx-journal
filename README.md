# fx-journal

FXトレードの週間振り返り（賢人のデイトレード手法）を公開するサイト。GitHub Pages（Jekyll・minima）で `https://kshojun.github.io/fx-journal/` に出る。

記事は非公開リポジトリ kshojun/fx-reports の `note/YYYY-MM-DD.md` から `scripts/journal_export.py` で書き出す（土曜の振り返りタスクが自動で行う）。ここを直接編集してもよい。

- `_posts/YYYY-MM-DD-weekly-review.md`：記事
- `assets/img/`：チャート画像
