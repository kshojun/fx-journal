# fx-journal

FXトレードの週間振り返り（賢人のデイトレード手法）を公開するサイト。GitHub Pages（Jekyll・minima）で `https://kshojun.github.io/fx-journal/` に出る。

記事は非公開リポジトリ kshojun/fx-reports の `note/YYYY-MM-DD.md` から `scripts/journal_export.py` で書き出す（平日朝の毎朝のプランと、土曜の週間振り返りを、それぞれのタスクが自動で行う）。ここを直接編集してもよい。

- `_posts/YYYY-MM-DD-daily-plan.md`：毎朝のプラン
- `_posts/YYYY-MM-DD-weekly-review.md`：週間振り返り
- `assets/img/`：チャート画像
